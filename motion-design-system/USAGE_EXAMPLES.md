# Exemplos de Uso e Escopo de Demonstração

## 1. Exemplo de Padronização Desejada

**Solicitação ao agente:**
> "Crie uma animação explicando como funciona a internet."

**Resultado esperado com a mesma linguagem visual em todos os elementos:**
1. Um personagem utilizando um notebook.
2. Um roteador com ondas de sinal.
3. Um conjunto de servidores.
4. Linhas conectando os elementos (`Draw On`).
5. Ícones representando pacotes de dados.
6. Uma sequência visual coesa explicando a comunicação ponta a ponta.

---

## 2. Projeto de Demonstração (Validação do Sistema)

Antes de produzir vídeos definitivos, o Antigravity deve gerar um projeto de demonstração (10 a 15 segundos) em **16:9** e **9:16** cobrindo seis blocos:

1. Introdução de personagem (`Character` + `CharacterPose`).
2. Personagem interagindo com objetos (`AnimatedObject`).
3. Transições geométricas animadas (`MotionTransition` + `GeometricShape`).
4. Um ambiente ilustrado completo (`Scene` + `Background` + `Shadow`).
5. Um infográfico animado (`Infographic` + `Callout`).
6. Uma composição final com tipografia (`AnimatedText`).
