# REF-001 — Cena de personagem em ambiente de trabalho

## O que aproveitar
- Simplicidade das formas do personagem.
- Proporção entre cabeça e corpo.
- Cantos arredondados dos objetos.
- Distribuição dos elementos.
- Uso de cores contrastantes.
- Sombra discreta abaixo dos objetos.

## O que não copiar
- Não reproduzir exatamente o personagem.
- Não copiar logotipos ou elementos de marca.
- Não reproduzir a composição inteira de maneira idêntica.

## Aplicação
Usar como orientação para criar personagens e cenários originais no estilo Modern Explainer.
