# Modern Explainer — Guia de Identidade Visual

Este manual define as regras fundamentais de direção de arte que o Antigravity deve consultar antes de criar qualquer cena ou componente animado no Remotion.

---

## 1. Linguagem das Ilustrações

### Princípios Obrigatórios
- Ilustrações vetoriais 2D com aparência profissional.
- Formas simples e reconhecíveis.
- Personagens com cabeça, corpo e membros simplificados.
- Olhos, boca e expressões discretas.
- Geometria arredondada, sem exagerar no aspecto infantil.
- Poucos detalhes internos.
- Objetos reconhecíveis por silhuetas.
- Aparência contemporânea de estúdio de Motion Design.

### O Que Evitar
- Desenhos infantis ou estética cartoon exagerada.
- Personagens de jogos.
- Aparência de apresentação corporativa antiga ou genérica.
- Gradientes excessivos ou metálicos.
- Sombras pretas pesadas.
- Detalhes visuais desnecessários ou elementos decorativos aleatórios sem função narrativa.
- Estilos de ilustração inconsistentes entre objetos da mesma cena.

---

## 2. Biblioteca de Formas e Objetos

| Elemento | Padrão |
| :--- | :--- |
| **Círculos** | Perfeitos, sem deformações excessivas |
| **Retângulos** | Cantos arredondados |
| **Linhas** | Finas e uniformes |
| **Setas** | Simples e expressivas |
| **Cards** | Bordas suaves |
| **Ícones** | Vetoriais e consistentes |
| **Objetos** | Geometria simplificada |

**Regra construtiva:** o agente deve ser capaz de montar objetos cotidianos — como computador, casa, pessoa, árvore, carro ou mercado — combinando essas primitivas geométricas com o mesmo peso visual.

---

## 3. Paleta de Cores

### Paleta de Referência — Modern Explainer

| Papel | Cor | Hex |
| :--- | :--- | :--- |
| Cor dominante | Azul | `#2457D6` |
| Cor de destaque / contraste | Âmbar | `#FFB84D` |
| Cor secundária | Coral | `#F16D5B` |
| Cor secundária | Verde | `#63B98B` |
| Base / fundo | Neutro | `#F3F4F6` |

### Proporção Indicativa de Uso
- **60%** cores neutras
- **25%** cor dominante
- **10%** cores secundárias
- **5%** cor de destaque

> Essa proporção serve como guia de equilíbrio visual para a composição, não como obrigação matemática rígida. Cada projeto pode definir sua própria paleta sem alterar a linguagem das ilustrações.

---

## 4. Cenários e Composição

- Fundo sólido ou com variação tonal muito discreta.
- Poucos elementos por cena.
- Objetos distribuídos com equilíbrio.
- Espaço negativo preservado para textos e informações.
- Hierarquia espacial clara com elementos em **primeiro**, **segundo** e **terceiro plano**.
- Ausência de detalhes decorativos sem função narrativa.
- Foco visual inequívoco: a composição deve deixar claro onde o espectador deve olhar.

---

## 5. Profundidade e Sombras

A profundidade deve ser discreta e limpa:
- Sombras difusas e suaves.
- Deslocamento pequeno entre o objeto e sua sombra.
- Sobreposição de camadas para sugerir profundidade.
- Nunca usar sombras pretas pesadas.
- Evitar gradientes metálicos e efeitos excessivos.

---

## 6. Checklist de Controle de Qualidade

Antes de aprovar uma cena ou componente, verificar:
- [ ] Consistência visual entre todos os elementos.
- [ ] Proporções corretas de personagens e objetos.
- [ ] Consistência da paleta de cores.
- [ ] Timing e fluidez das animações.
- [ ] Ausência de cortes inesperados (*clipping*).
- [ ] Ausência de sobreposição acidental de elementos ou textos.
- [ ] Compatibilidade de renderização no Remotion (16:9 e 9:16).
- [ ] Reutilização real dos componentes via props.
